# DevRadar

DevRadar is an early-development, local-first Obsidian plugin for following selected GitHub users and recording supported public developer activity in connected Markdown notes.

Installation and usage documentation will be added as the MVP develops.

The project is privacy-respecting by design. It is intended to help users keep personal research notes up to date without requiring a backend, hosted account, or telemetry.
